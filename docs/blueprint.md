# **App Name**: ReviewSpark

## Core Features:

- Admin Configuration: Admin panel for uploading company logo, adding a short description, and inputting keywords/tags related to the business.
- Public Review Page: Display the company logo, a welcome message ('We’d love your feedback! Please leave us a review.'), AI-generated reviews, copy-to-clipboard buttons for each review, and a 'Leave a Google Review' button that opens the specified Google Maps review link.  Generate 3-5 initial review suggestions using AI based on the company description and keywords. A 'Regenerate Suggestions' button fetches a new set of reviews, using the same keywords as a tool.

## Style Guidelines:

- Primary color: Clean white or light gray for the background to ensure readability.
- Secondary color: A professional blue (#3498db) for primary buttons and interactive elements.
- Accent: A warm orange (#e67e22) for the 'Regenerate Suggestions' button and to highlight key actions.
- Clear and readable sans-serif fonts for body text and headings.
- Simple, modern icons for copy-to-clipboard and other actions to ensure clarity.
- Clean, organized layout with clear sections for the logo, welcome message, review suggestions, and call-to-action buttons.
